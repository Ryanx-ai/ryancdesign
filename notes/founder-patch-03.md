# Founder walkthrough 03

## Implementation direction

Preserve RCD's black/cyan shell, Inter/EB Garamond hierarchy, existing motion,
navigation, résumé and original artwork. No dependencies or generated artwork.

- Gallery: one 16:10 grid, four/two/one columns, restrained bottom-left captions.
  Original logo covers remain contained against matching backgrounds; photographic
  work fills the frame. Curated order is separate from factual design dates.
- Phings: reuse the original pale-green Pangea wordmark and landscape. A large
  terrarium sits beside a small Grow/Destroy tool panel. Drag/drop and keyboard/
  touch placement have the same result. Changes are local design-demo state, not
  a released game, ecosystem simulation or AI behaviour.
- Pufflet: keep ink/cream/lime/lavender, original identity and existing UI. Explain
  the founder's deployment frustration in short, first-person prose.
- Luna: keep Moonlight Black/violet and the actual Brand → Wrap → Collection →
  Share model. Replace metaphors with descriptive labels.
- Eureka: publish prominently without inventing a historical date. Use documented
  module/programme/morsel workflows and clearly illustrative sample content.
  The founder supplied the correct local Eureka folder during this pass. Its
  documentation, Flask code, original stylesheet and main workflow templates
  became readable after download. The original white/black/orange palette,
  department-grouped library and programme-details flow inform the new UI study.
  The base template is still iCloud-dataless, so no original running-app capture
  is claimed. No private databases or curriculum content are used.

## Review criteria

Equal card dimensions; no distorted logos; no duplicate Pangea; clear concept
labels; meaningful, accessible interactions; concise copy without invented
outcomes. Inspect desktop/tablet/390px, then lint, typecheck, build, Git safety
review and verified production deployment.

## Validation record

- All 21 published portfolio cards use 16:10 dimensions at desktop, tablet and
  390px mobile widths. The four recent studies appear first without invented dates.
- Original Pangea artwork is used for Phings; no second published Pangea entry.
- Phings supports native drag/drop and click/keyboard placement with visible grow
  and destroy states. Its scripted concept status remains explicit.
- Pufflet's sample deployment success/failure/retry flow and Luna's collection,
  preview and local publication/history flow were exercised without external writes.
- Eureka search, empty results, edit validation, save, programme details and
  add/remove selection were checked. All changes reset on reload.
- Original legacy media, shell, navigation, résumé, dependencies and background
  effects are unchanged. New covers use code-generated SVG/PNG, not new AI artwork.
- Final lint and typecheck passed; the production build generated all 36 pages,
  including all 21 published portfolio case studies. The final source-credit
  wording is included in the release build.
